# 🔢 Contador de Cliques

Aplicação web interativa desenvolvida em React para praticar manipulação de estados e eventos de clique. 

Este projeto foi desenvolvido como parte dos testes de aprendizado do **Curso DEV START Senai**.

## 🚀 Tecnologias utilizadas
* **React**
* **JavaScript (ES6+)**
* **CSS3**

## ✨ Funcionalidades
* Incrementar o valor do contador.
* Zerar o valor do contador.
* Interface simples e responsiva.

## 💻 Como executar o projeto

Clone o repositório e instale as dependências:

```bash
git clone [https://github.com/luizavicktoria/contador-de-cliques.git](https://github.com/luizavicktoria/contador-de-cliques.git)
cd contador-de-cliques
npm install
npm start
